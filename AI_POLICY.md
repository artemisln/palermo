# AI policy

You can use AI to contribute to Palermo. I built a lot of this app with coding agents myself, and I'm happy to get pull requests written with Claude Code, Cursor, Copilot or anything else.

The rules below exist because generating code is now fast and reviewing it is still slow. This is a small project with one maintainer, so please keep the review cost in mind.

## You own what you submit

Your name is on the pull request, so treat every line as if you typed it. Before you open one:

- Read the whole diff and make sure you can explain each change.
- Run `npm test`, `npm run lint` and `npx tsc --noEmit`, and fix what fails.
- Try the change in the app (`npx expo start`) if it touches anything a player sees.
- Delete whatever the agent added that the change does not need: extra files, unrelated refactors, new dependencies, commented-out code, debug logs.

Only say a test passed or a bug is fixed if you checked it. "The AI wrote it" doesn't make a bug acceptable, and it doesn't count as proof the code works either.

## Keep it small

One pull request, one change. A focused fix with a test is easy to merge. A 2,000-line agent rewrite of the whole app is not, and I will probably close it without a full review. If you want to add something big, like a new role or a rule change, open an issue first so we can agree on how it should play.

These usually get closed:

- Large generated diffs that the author clearly has not read.
- Repo-wide reformatting or renaming with no real reason.
- Speculative fixes for bugs nobody reproduced.
- Many near-identical issues or pull requests opened by a bot.

## Disclosure is optional

You don't have to say that AI helped. If you used an interesting workflow (a custom agent setup, a skill, a prompt that worked well), feel free to mention it in the pull request. I'd like to read about it.

## Talk to me yourself

AI can help you understand a review comment. But reply in your own words and show that you looked at the code. Please don't paste model output into review threads.

## Agent setup

[AGENTS.md](AGENTS.md) has the commands, project structure and rules a coding agent needs. Claude Code, Codex, Cursor and most other agents read it automatically. There is also a Claude Code skill for the most common contribution, adding an optional role, in [.claude/skills/add-role](.claude/skills/add-role/SKILL.md).

## Privacy and licensing

The app collects no data and works offline, and the App Store listing and [privacy policy](docs/privacy-policy.md) promise that. Agents like to add analytics, crash reporting or network calls "for later". Those changes will not be merged.

Only submit code you have the right to share under the [MIT license](LICENSE). Code generated by AI follows the same licensing rules as code you write yourself.
