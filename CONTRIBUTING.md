# Contributing

Bug reports and small pull requests are welcome. Open an issue first for anything bigger, such as a new role or a rule change, since house rules for Palermo vary a lot between groups. Game rules live in `lib/` and are covered by the tests in `__tests__/`, so please run `npm test` and `npm run lint` before opening a pull request, and add a test when you change a rule. Using AI to write your change is fine: read [AI_POLICY.md](AI_POLICY.md) first, and point your agent at [AGENTS.md](AGENTS.md).
